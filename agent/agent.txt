PHASE 3 — DATA LEAKAGE AND TEMPORAL ALIGNMENT AUDIT
====================================================================

This is critical for financial time-series models.

Audit all input modalities.

A. Technical features

Verify:

1. Technical indicators use only past and current data up to time t.
2. Rolling windows do not include future rows.
3. No `shift(-n)` is applied to features unless explicitly part of target construction.
4. Returns are calculated consistently.
5. Indicators such as RSI, MACD, moving averages, Bollinger Bands, etc. do not lookahead.
6. Features are scaled using scaler fitted only on training data.

B. Macro features

Macro variables are low-frequency and dangerous if forward-filled naively.

Verify:

1. Macro data uses official publication/release date, not only period date.
2. A January macro value should not be available before its release date.
3. Forward-fill must only fill data after the release date.
4. There is no future macro information leaked into daily rows.
5. Macro encoder training does not use test-period information.
6. Macro features are normalized using train-only statistics.

If publication dates are unavailable, document this limitation and create a conservative lag assumption, for example:

- monthly macro data becomes available only on the first day of the following month,
- or after a fixed lag such as 5 business days.

C. News embeddings

Verify:

1. Daily news embedding for date t contains only news available before prediction time.
2. If prediction is made at close of day t, news after close should not be included.
3. Missing news days are handled explicitly.
4. Forward-filling news embeddings is not silently leaking old information unless intended.
5. Embeddings are precomputed outside the training loop and aligned by date.
6. No embedding is computed using future corpus information.

D. Windowing

For lookback window L=28:

Verify:

- window at time t contains rows t-L+1 to t,
- target corresponds to future return after t,
- no target information is inside the window,
- no global normalization was fitted on the full dataset.

E. Add leakage tests

Create or extend tests:

tests/unit/test_no_lookahead.py

Include tests such as:

1. Mutating future rows does not affect current feature rows.
2. Scaler transform uses train-only fitted parameters.
3. Macro values before release date are NaN or conservative lagged values.
4. News embedding date matches prediction date and not future date.
5. Dataset builder does not shuffle chronological samples.
